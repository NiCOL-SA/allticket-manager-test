# 券管理クラウド版 v3

## 今回の変更
- 「券を使用」ボタンは従来どおり残す
- 各地区の「昼」「夜」表示そのものをタップ可能に変更
- 直接タップした場合は1枚使用
- 「日付・時刻」「○○・昼/夜を使用しますか？」を表示
- 「キャンセル」「OK」で確定
- 在庫0枚の券は直接使用できない
- 使用履歴には日付時刻・端末名を保存する想定

## 期間切替
前半: 毎月1日 09:00 〜 16日 08:59
後半: 毎月16日 09:00 〜 翌月1日 08:59

例:
- 9/1 08:30 → 8月後半
- 9/1 09:00 → 9月前半
- 9/16 08:59 → 9月前半
- 9/16 09:00 → 9月後半
